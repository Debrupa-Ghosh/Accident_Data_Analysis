# Accident_Data_Analysis
This is Data Analysis Project based on Accident data with the following Data like Road Type, Location,Weather Condition,Vehicle Type,Road Condition, Accident Severity etc. I have analyzed how the folllowing parameters impact accident severity. I have also discovered the accident prone zones and counted the number of accidents per area. 


Tools Used :
1. Numpy & Pandas : To perform mathematical computing and data manupulation.
2. Matlpotlib & Seaborn : Visualize the impact of different paraemeters with accident severity using line chart, histogram, count plot & bar plot.
3. Folium : Used to visualize the accident prone zones and their count in the real time map.
